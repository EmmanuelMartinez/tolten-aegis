## [0.1.0] - 2026-09-10

### Added

- Constitution injection into every model step (`.agents/rules/DEEPSEEK.md` + fallbacks).
- Knowledge tools: `agents_index`, `agents_read`, `agents_search`.
- MCP management for both scopes (global `~/.dsh/aegis-mcp.json`, project `.agents/mcp.json`).
- Control Center panel with live status, MCP and knowledge editing.
- Agent preset + `template/.agents` scaffolding for any project.
